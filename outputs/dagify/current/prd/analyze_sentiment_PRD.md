# analyze_sentiment PRD

## Description
Analyze the sentiment of the news articles.


## Conceptual Info

The node takes concise article summaries and determines the overall sentiment of each article, returning a list of indices, sentiment categories, and confidence scores.

## Docstring

### Summary
Analyze the sentiment of news article summaries.

### Parameters

- **summaries** (List[str]): A list of concise summaries generated by `summarize_news_articles`.

### Returns

dict: A dictionary with keys `article_index`, `sentiment_category`, and `sentiment_confidence`, each mapping to a list of the same length as the input `summaries`.

### Raises

- ValueError: Raised if `summaries` is empty or contains non-string entries.

### Examples

```python
>>> results = analyze_sentiment(['Neutral news about weather'])
{'article_index': [0], 'sentiment_category': ['neutral'], 'sentiment_confidence': [0.65]}
```
