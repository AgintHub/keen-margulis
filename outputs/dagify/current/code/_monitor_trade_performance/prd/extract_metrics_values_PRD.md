# extract_metrics_values PRD

## Description
Extracts numerical performance metrics from the provided performance data string.


## Conceptual Info

This shim function is designed to extract numerical performance metrics from a given string representation of performance data, which is expected to be generated by the calculate_performance_metrics function.

## Docstring

### Summary
Extracts numerical performance metrics from the input performance data string.

### Parameters

- **performance_data** (str): A string representation of performance metrics calculated by the calculate_performance_metrics function.

### Returns

List[float]: A list of numerical performance metrics extracted from the input string.

### Raises

- ValueError: If the input string is malformed or cannot be parsed into numerical metrics.
- TypeError: If the input is not a string.

### Examples

```python
>>> performance_data = 'returns:0.05,Sharpe_ratio:1.2,max_drawdown:0.15'
>>> extracted_metrics = extract_metrics_values(performance_data)
[0.05, 1.2, 0.15]
```

```python
>>> performance_data = 'metric1:10,metric2:20.5,metric3:30.2'
>>> extracted_metrics = extract_metrics_values(performance_data)
[10.0, 20.5, 30.2]
```
