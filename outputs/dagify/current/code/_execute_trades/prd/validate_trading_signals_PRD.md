# validate_trading_signals PRD

## Description
Validates a list of trading signals and returns a list of validated signals.


## Conceptual Info

This shim node is responsible for validating trading signals generated by the system. It takes in a string of trading signals, processes them, and returns a list of validated signals that can be used for further processing or execution.

## Docstring

### Summary
Validates trading signals and returns a list of valid signals.

### Parameters

- **signals** (str): A string containing trading signals separated by commas or another delimiter.

### Returns

List[str]: A list of validated trading signals.

### Raises

- ValueError: If the input string is malformed or contains invalid signals.
- TypeError: If the input is not a string.

### Examples

```python
>>> validate_trading_signals(signals='buy,sell,hold')
['buy', 'sell', 'hold']
```

```python
>>> validate_trading_signals(signals='invalid_signal,buy,sell')
['buy', 'sell']
```
