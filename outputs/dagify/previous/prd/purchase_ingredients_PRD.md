# purchase_ingredients PRD

## Description
Purchase the ingredients needed for cooking.


## Conceptual Info

This node is responsible for purchasing the ingredients required for cooking a meal based on the shopping list generated by the 'create_shopping_list' node.

## Docstring

### Summary
Purchase ingredients based on the shopping list.

### Parameters

- **shopping_list** (List[str]): List of ingredients to purchase, generated by the 'create_shopping_list' node.

### Returns

List[str]: List of ingredients that were purchased.

### Raises

- ValueError: If the shopping list is empty or contains invalid ingredients.

### Examples

```python
>>> shopping_list = ['eggs', 'flour', 'sugar']
>>> purchased_ingredients = purchase_ingredients(shopping_list)
['eggs', 'flour', 'sugar']
```

```python
>>> shopping_list = []
>>> purchased_ingredients = purchase_ingredients(shopping_list)
[]
```
