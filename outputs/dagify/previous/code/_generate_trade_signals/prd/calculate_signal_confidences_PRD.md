# calculate_signal_confidences PRD

## Description
Calculates signal confidences based on trend indicators, trend directions, and trade signals.


## Conceptual Info

This shim node is responsible for calculating signal confidences based on the provided trend indicators, trend directions, and trade signals. It plays a crucial role in determining the reliability of trade signals generated by the system.

## Docstring

### Summary
Calculates signal confidences based on trend indicators, trend directions, and trade signals.

### Parameters

- **trend_indicators** (str): Serialized list of trend indicators (List[float]).
- **trend_directions** (str): Serialized list of trend directions (List[str]).
- **trade_signals** (str): Serialized list of trade signals (List[str]).

### Returns

List[float]: List of signal confidences corresponding to the input trade signals.

### Raises

- ValueError: When the input lists are of different lengths or when the deserialization of input strings fails.
- TypeError: When the input types are not as expected (e.g., trend indicators are not numbers).

### Examples

```python
>>> import json
>>> trend_indicators = json.dumps([0.5, 0.7, 0.3])
>>> trend_directions = json.dumps(['up', 'down', 'neutral'])
>>> trade_signals = json.dumps(['buy', 'sell', 'hold'])
>>> signal_confidences = calculate_signal_confidences(trend_indicators, trend_directions, trade_signals)
[0.8, 0.4, 0.6]
```
